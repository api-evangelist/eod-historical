# EOD Historical Data

EOD Historical Data (EODHD) provides institutional-grade financial data through a REST API covering
150,000+ tickers across 60+ global exchanges. The API spans end-of-day historical prices (30+ years),
real-time OHLCV, intraday bars, fundamentals, ETF data, options chains with Greeks, dividends,
splits, technical indicators, financial news with sentiment, macroeconomic indicators, ESG data,
and WebSocket streaming.

**Base URL:** `https://eodhd.com/api`  
**Auth:** `api_token` query parameter  
**Formats:** JSON, CSV, XML  
**Plans:** Free (20 calls/day) to $99.99/month All-In-One  

**Provider:** [eodhd.com](https://eodhd.com/)  
**Docs:** [eodhd.com/financial-apis/](https://eodhd.com/financial-apis/)  
**OpenAPI:** [github.com/EodHistoricalData/EODHD-openapi](https://github.com/EodHistoricalData/EODHD-openapi)
